# 리포트에 특정 계정이 있는지 찾는 법

증권사 리포트 표에 찾는 계정 행(예: 순자산(Book Value), CFPS)이 찍혀 있는지를 어드민 데이터로 찾는 방법. 계정 이름만 바꿔 넣으면 됨. PDF는 받지 않고 조회(GET)만 함. 사람이 직접 콘솔에서 돌려도 되고, Claude에게 이 문서를 주고 맡겨도 됨.

## 1. 준비: Claude in Chrome 설치·연결

Claude에게 맡길 때만 필요. 사람이 직접 돌리면 2절로 넘어감.

### 1-1. 필요한 것

| 항목 | 내용 |
|---|---|
| Claude 요금제 | 유료 요금제(Pro, Max, Ultra, Team, Enterprise) |
| 브라우저 | Google Chrome (Claude Code 쪽 안내상 Microsoft Edge도 됨) |
| 어드민 | 내 브라우저에서 `bo.niceinvesting.com` 로그인 가능 |
| 회사 계정(Team·Enterprise) | 조직 관리자가 '조직 설정 → Claude in Chrome'을 켜 둬야 함. 관리자가 사이트 허용·차단 목록을 쓰면 `bo.niceinvesting.com`이 허용돼 있어야 함 |

### 1-2. 확장 설치

1. Chrome 열기
2. Chrome 웹 스토어의 Claude in Chrome 페이지 열기: https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn
3. 'Chrome에 추가' 클릭
4. 나오는 창에서 Claude 계정으로 로그인 (Claude 앱에 쓰는 계정·조직과 같아야 함)
5. 주소창 오른쪽 퍼즐 모양 아이콘 → Claude 옆 핀 눌러 고정
6. 확장이 요청하는 권한 허용 (탭 열기·닫기, 페이지 읽기, 클릭·입력 등)

### 1-3. Claude와 연결

**Claude 데스크톱 앱(채팅·Cowork·Code 탭)**

1. 왼쪽 아래 내 이름(이니셜) 클릭 → 설정(Settings)
2. Customize → Connectors
3. Claude in Chrome 찾아 Configure → 켜기
4. 이 커넥터는 기본이 꺼짐이라 대화마다 켜야 함

**Claude Code(터미널)**

1. `claude --chrome`으로 시작 (처음 한 번 안내 창 → Enter)
2. `/chrome` 입력 → 상태 창에 `Status: Enabled`, `Extension: Installed`가 보이면 연결됨
3. 매번 켜려면 `/chrome`에서 기본 사용(Enabled by default) 선택
4. API 키로 로그인한 Claude Code에서는 안 됨 (`/login`으로 계정 로그인 필요)

### 1-4. 연결 확인

Claude에게 아래처럼 요청.

```text
Claude in Chrome으로 https://bo.niceinvesting.com/research/report 를 열어서 화면 제목만 알려줘. 저장이나 버튼 클릭은 하지 마.
```

- Chrome에 새 탭(Claude 탭 그룹)이 열리고 'NIV Admin Hub' 같은 제목이 나오면 성공
- 로그인 화면(Microsoft)이 나오면 그 탭에서 직접 로그인 후 '로그인했어'라고 말하면 Claude가 이어서 함

### 1-5. 안 될 때

| 증상 | 확인할 것 |
|---|---|
| Browser extension is not connected | 확장과 Claude 앱이 같은 계정·같은 조직으로 로그인됐는지. Chrome과 Claude 앱 다시 시작 |
| 확장이 안 잡힘(Not detected) | `chrome://extensions`에서 Claude 확장이 켜져 있는지. 처음 연결이면 Chrome을 한 번 껐다 켬 |
| 한동안 쓰다가 끊김 | 확장이 쉬는 상태로 들어간 것. Claude Code는 `/chrome` → Reconnect extension, 앱은 대화에서 커넥터 다시 켜기 |
| 회사 정책으로 꺼져 있음 | 조직 관리자에게 Claude in Chrome 사용·`bo.niceinvesting.com` 허용 요청 |

참고: Claude 데스크톱 앱 Code 탭에는 앱 안의 '내장 브라우저'도 있음. 내장 브라우저는 Chrome과 로그인이 따로라서, 내장 브라우저로 하려면 그 안에서 어드민에 다시 로그인해야 함.

## 2. 찾는 기준

- 표의 행 이름(라벨)이 찾는 계정 이름과 같으면 그 계정 행으로 셈
- 같은지 볼 때: 띄어쓰기·대소문자·각주 `*` 무시, 앞의 '연결' 무시, 괄호 안이 단위뿐이면 무시('CFPS(원)' = 'CFPS'). '(지배)' 같은 괄호는 남김
- 이름이 라벨 안에 들어만 있는 행('수정 Book Value')은 '비슷한 라벨'로 따로 표시. 3글자 이하 이름('순자산', 'BV')은 같은 이름만 찾음
- 비슷한 라벨에서 뺄 말을 따로 줌 ('주당', 'BPS' 등)
- 라벨 바로 다음 줄(단위 줄 `(억원)`은 건너뜀)이 숫자여야 표의 행으로 셈

계정별 예

| 찾는 계정 | `LABELS` (같은 뜻 이름) | `EXCLUDE` (비슷한 라벨에서 뺄 말) |
|---|---|---|
| 순자산(Book Value) | `['순자산', 'Book Value', 'BV', '순자산(Book Value)']` | `['주당', 'BPS', 'BVPS', 'per share', 'PBR', 'EV(']` |
| CFPS | `['CFPS', 'Cash Flow Per Share']` | `[]` |
| 차입금 | `['차입금', '총차입금', 'Total borrowings']` | `['단기', '장기', '비율', '순차입금']` |

## 3. 원천 (운영 어드민 API, 조회만)

| 용도 | 경로 | 쓰는 값 |
|---|---|---|
| 리포트 목록 | `GET /api/reports?page=1&limit=1000&tab=review&clsfCd=COM&fromDate=&toDate=` | `id`, `broker`, `stock_name`, `report_date` |
| 원문 텍스트 | `GET /api/reports/{id}/extracted-data` | `basicInfo.raw_extraction.data.markdown_text` |

- 인증: 어드민 로그인 상태에서 `GET /api/auth/session` → `accessToken` → `Authorization: Bearer {토큰}`
- 목록 필터: `firmName`(증권사), `companyName`, `title`, `reviewerName`(검수자 이름), `reviewStage=done`(검수 완료)
- 목록은 발행일 내림차순, `limit` 최대 1000

## 4. 찾는 순서

1. 목록을 범위(발행일·분류 등)로 한 번 받음
2. 리포트마다 원문 텍스트를 1건씩 받음 (1.5초 간격)
3. 원문 텍스트를 줄 단위로 나눔
4. 2절 기준으로 계정 행이 있는 리포트를 모음

## 5. 주의

- 원문 텍스트는 표의 칸마다 줄이 나뉨. 라벨 줄에는 숫자가 없음. 한 줄에 라벨과 숫자가 같이 있는 줄을 찾으면 0건이 나옴

  ```text
  자본총계
  21,292
  28,875
  수정 Book Value
  26,413
  32,892
  ```

- 행이 있는지만 봄. 숫자의 연도·단위·추정치 여부는 안 봄
- 이미지 PDF는 원문 텍스트가 빈 값이라 못 찾음 → 결과의 '텍스트 없음' 건수만큼은 PDF를 직접 봐야 함 (11-19 표본 60건 중 19건)
- 긴 라벨이 두 줄로 쪼개진 표는 놓칠 수 있음
- 서버 부담: 전체 목록(약 4만 건)을 받지 않음. 상세 조회는 동시에 여러 건 보내지 않고 1건씩. PDF는 받지 않음
- 어드민의 저장·검수 완료·메타 저장 버튼은 누르지 않음

## 6. 실행 스크립트

어드민 리포트 목록 화면(`https://bo.niceinvesting.com/research/report`)에서 F12 → Console에 붙여 넣고 실행. 맨 위 설정만 바꿔서 씀.

| 설정 | 뜻 |
|---|---|
| `LABELS` | 찾을 계정 이름 (같은 뜻 표현 여러 개) |
| `LIKE` | 비슷한 라벨도 표시 (`true`/`false`) |
| `EXCLUDE` | 비슷한 라벨에서 뺄 말 |
| `Q` | 목록 범위. 예: 증권사로 좁히기 `firmName: '한화투자증권'` |
| `MAX` | 최대 건수 |
| `DELAY` | 1건당 간격(ms) |

- 실행하면 바로 `시작: N건`이 나오고 뒤에서 1건씩 돎 (20건마다 진행 표시, 끝나면 콘솔 표)
- 진행·결과는 `window.__scan`에 쌓임 (`n` 확인 건수, `out` 찾은 리포트, `done` 끝남)
- 중간에 멈추기: `__scan.stop = true`

```js
(async () => {
  const LABELS = ['순자산', 'Book Value', 'BV', '순자산(Book Value)'];
  const LIKE = true;
  const EXCLUDE = ['주당', 'BPS', 'BVPS', 'per share', 'PBR', 'EV('];
  const Q = { page: 1, limit: 1000, tab: 'review', clsfCd: 'COM', fromDate: '2026-09-01', toDate: '2026-11-19' };
  const MAX = 300, DELAY = 1500;

  const UNITW = /^(%|원|배|x|조원|십억원|억원|백만원|천원|보통주?|현금|원\/주|연결)$/;
  const norm = s => String(s).toLowerCase().replace(/[\s*]/g, '').replace(/^연결(?=.)/, '')
    .replace(/\(([^()]*)\)/g, (m, t) => (t.split(',').every(w => UNITW.test(w)) ? '' : m));
  const SAME = new Set(LABELS.map(norm)), PART = [...SAME].filter(x => x.length >= 4), EX = EXCLUDE.map(norm);
  const kind = l => {
    const n = norm(l);
    if (!n || l.length > 40) return null;
    if (SAME.has(n)) return '같은 이름';
    if (LIKE && PART.some(p => n.includes(p)) && !EX.some(x => n.includes(x))) return '비슷한 라벨';
    return null;
  };
  const NUM = /^[-(△▲]?\s*[\d,.]+\)?%?$/;
  const numNext = (L, i) => {
    for (let j = i + 1; j < Math.min(L.length, i + 3); j++) {
      if (NUM.test(L[j])) return true;
      if (!UNITW.test(L[j].replace(/[\s()]/g, ''))) return false;
    }
    return false;
  };

  const tok = (await fetch('/api/auth/session').then(r => r.json())).accessToken;
  const H = { headers: { Authorization: 'Bearer ' + tok } };
  const list = (await fetch('/api/reports?' + new URLSearchParams(Q), H).then(r => r.json())).data
    .filter(d => d.stock_name).slice(0, MAX);
  const S = (window.__scan = { labels: LABELS.join(', '), n: 0, total: list.length, out: [], noText: 0, err: 0, done: false, stop: false });
  (async () => {
    for (const d of list) {
      if (S.stop) break;
      try {
        const ed = await fetch(`/api/reports/${d.id}/extracted-data`, H).then(r => r.json());
        const md = ed.basicInfo?.raw_extraction?.data?.markdown_text || '';
        if (!md) S.noText++;
        const L = md.split('\n').map(s => s.trim()).filter(Boolean);
        const hits = L.flatMap((l, i) => { const k = kind(l); return k && numNext(L, i) ? [{ k, row: L.slice(i, i + 6).join(' | ') }] : []; })
          .sort((a, b) => (a.k === '같은 이름' ? 0 : 1) - (b.k === '같은 이름' ? 0 : 1));
        if (hits.length) S.out.push({ 증권사: d.broker, 종목: d.stock_name, 발행일: d.report_date, 구분: hits[0].k, 행: hits[0].row, 행수: hits.length, id: d.id });
      } catch (e) { S.err++; }
      if (++S.n % 20 === 0) console.log(`${S.n}/${S.total} 확인, 찾음 ${S.out.length}`);
      await new Promise(z => setTimeout(z, DELAY));
    }
    S.done = true;
    console.log(`끝: ${S.n}건 중 ${S.out.length}건, 텍스트 없음(이미지 PDF) ${S.noText}건, 오류 ${S.err}건`);
    console.table(S.out);
  })();
  return `시작: ${list.length}건`;
})();
```

## 7. Claude(브라우저 도구)로 실행할 때

1절대로 연결된 Claude에게 이 문서를 주고 "6절 스크립트로 LABELS = [...], 범위 ○○ 찾아줘"라고 요청. Claude가 지킬 것:

- 조회만. 저장·검수 완료·메타 저장 버튼은 누르지 않음. 전체 목록(약 4만 건) 받지 않음. 상세 조회는 1건씩
- 로그인 화면이 나오면 멈추고 사람에게 로그인을 요청
- 실행: 6절 스크립트를 그대로 실행 → `시작: N건`이 바로 돌아옴. 끝날 때까지 한 번에 기다리지 않음 (도구 한 번 실행이 45초 넘으면 끊김)
- 진행 확인: 40초마다 아래를 실행, `done`이 true 가 될 때까지

  ```js
  await new Promise(z => setTimeout(z, 40000));
  JSON.stringify({ n: __scan.n, total: __scan.total, found: __scan.out.length, noText: __scan.noText, err: __scan.err, done: __scan.done });
  ```

- 결과 읽기: 콘솔 표는 Claude가 못 읽음 → 아래 실행 결과를 받음. URL이나 `a=b` 꼴 글자가 섞이면 확장이 결과를 막을 수 있어 칸은 ` ; `로 구분하고, 어드민 링크는 따로 만듦 (`https://bo.niceinvesting.com/research/report/{id}`)

  ```js
  __scan.out.map(o => [o.증권사, o.종목, o.발행일, o.구분, o.행, o.행수, o.id].join(' ; ')).join('\n');
  ```

- 결과가 길어 잘리면 `__scan.out.slice(0, 20)`처럼 나눠 읽음
- 끝나면 연 탭을 닫음
